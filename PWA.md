# V&A Hire — PWA (Progressive Web App)

## Overview

V&A Hire is a Progressive Web App built with Vite + `vite-plugin-pwa`. Workers and supervisors can install it on their phone's home screen for a native app-like experience — no App Store needed.

## How It Works

### Service Worker (`sw.js`)
- Auto-generated by `vite-plugin-pwa` using Workbox
- **Precaches** all static assets (JS, CSS, HTML, images) for offline access
- **Runtime caching** for Google Fonts (CacheFirst strategy)
- **Navigation fallback** to `/index.html` for SPA routing (excludes `/api/` routes)
- **Auto-updates** on new deployments (`registerType: 'autoUpdate'`)

### Custom Service Worker (`public/sw-custom.js`)
Injected via `workbox.importScripts` — handles push notification events:
- `push` event: displays notification with title, body, icon, and action URL
- `notificationclick` event: focuses existing window or opens new one at the notification's URL

### Web App Manifest (`manifest.webmanifest`)
- **Name:** V&A Hire
- **Start URL:** `/shifts` (opens to available shifts)
- **Display:** `standalone` (no browser chrome)
- **Theme:** `#0a0a0a` (dark)
- **Icons:** 192x192 and 512x512 PNG (both `any` and `maskable` purposes)

## Installation

### iOS (Safari)
1. Visit `vandahire.com` in Safari
2. Tap the **Share** button (box with arrow)
3. Tap **Add to Home Screen**
4. The app icon appears on the home screen

An `InstallPrompt` component shows a tip guiding users through this process. It appears on the landing page and shifts page with a 24-hour dismiss cooldown.

### Android (Chrome)
1. Visit `vandahire.com` in Chrome
2. Chrome triggers `beforeinstallprompt` event automatically
3. The `InstallPrompt` component shows an **Install App** button
4. Tap to install — adds to home screen and app drawer

## Push Notifications

### Architecture
- **VAPID keys** stored in Vercel env vars (`VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`)
- **Subscriptions** stored in Supabase `push_subscriptions` table (one per worker, keyed by `worker_id`)
- **Server-side sending** via `web-push` npm library
- All push API routes consolidated into `api/worker.js` (to stay within Vercel Hobby 12-function limit)

### API Routes
| Route | Method | Description |
|---|---|---|
| `/api/worker?route=push-vapid-key` | GET | Returns VAPID public key for frontend |
| `/api/worker?route=push-subscribe` | POST | Stores push subscription for a worker (by phone) |
| `/api/worker?route=push-send` | POST | Sends push to a specific worker by ID |
| `/api/worker?route=push-notify-shift` | POST | Notifies all approved workers about a new shift (admin-only) |

### Frontend Files
- `src/lib/pushNotifications.js` — `subscribeToPush(phone)`, `isPushSupported()`, `isPushSubscribed()`
- `src/components/PushOptIn.jsx` — UI banner for opt-in (24-hour dismiss cooldown)

### When Push Notifications Are Sent
1. **New shift available** — admin triggers via `push-notify-shift` endpoint
2. **Geofence exit warning** — worker leaves event venue area (1st warning: push to worker, 2nd+: push to worker AND supervisor)
3. Future: shift reminders, assignment confirmations

### Expired Subscriptions
If a push send returns HTTP 410 or 404, the subscription is automatically deleted from the database.

## Vercel Configuration

### Headers (`vercel.json`)
```json
{
  "source": "/sw.js",
  "headers": [
    { "key": "Cache-Control", "value": "no-cache, no-store, must-revalidate" },
    { "key": "Service-Worker-Allowed", "value": "/" }
  ]
}
```

### SPA Rewrite Exclusions
The catch-all SPA rewrite excludes PWA files so they're served directly:
```
sw.js, sw-custom.js, manifest.webmanifest, registerSW.js, workbox-*
```

## Generating New VAPID Keys
```bash
npx web-push generate-vapid-keys
```
Set `VAPID_PUBLIC_KEY` and `VAPID_PRIVATE_KEY` in Vercel environment variables.

## Troubleshooting

### "Install" banner not showing
- **iOS:** There is no install prompt API on iOS. Users must manually use Share > Add to Home Screen. The `InstallPrompt` component shows a tip.
- **Android:** The `beforeinstallprompt` event only fires if the manifest is valid, the site is served over HTTPS, and a service worker is registered.
- Check browser DevTools > Application > Manifest for errors.

### Push notifications not arriving
- Check that `VAPID_PUBLIC_KEY` and `VAPID_PRIVATE_KEY` are set in Vercel env vars
- Check that the `push_subscriptions` table exists in Supabase
- Worker must have granted notification permission AND subscribed via the PushOptIn component
- iOS Safari does NOT support web push notifications (iOS 16.4+ supports it only for installed PWAs)

### Service worker not updating
- `sw.js` is served with `Cache-Control: no-cache, no-store, must-revalidate`
- `registerType: 'autoUpdate'` automatically activates new service workers
- If stale, users can force-refresh or clear site data
